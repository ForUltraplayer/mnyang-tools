## 어떤 도구인가요?

Microsoft 공식 도구로 설치 USB를 만듭니다. 나중에 이 USB로 부팅해 설치합니다.

Windows를 포맷하고 새로 설치하려 할 때 씁니다.

## 사용 전 확인

설치 USB를 만들면 선택한 USB의 내용이 지워집니다. Windows 설치 중 파티션을 포맷하거나 삭제하면 해당 파티션의 파일과 프로그램도 지워지므로 먼저 백업하세요.

사진·문서·게임 저장 파일·브라우저 즐겨찾기를 외장 드라이브나 클라우드에 먼저 백업하세요. 다시 설치하기 전에 Windows 정품 인증 상태와 설치할 에디션을 확인하세요.
