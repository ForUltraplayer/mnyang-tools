## 어떤 도구인가요?

ISO 파일을 골라 부팅 USB를 만듭니다. Windows 11 요구 사항(TPM·계정) 우회 옵션이 있습니다.

공식 도구가 안 되거나 ISO 파일로 USB를 만들 때, 또는 요구 사항 검사를 건너뛰어야 할 때 씁니다.

## 사용 전 확인

USB 내용이 지워집니다. ISO는 Microsoft 공식 페이지에서만 받으세요.

Windows 설치 중 파티션을 포맷하거나 삭제하면 해당 파티션의 자료가 지워집니다. 설치할 드라이브를 확인하고 먼저 백업하세요.
